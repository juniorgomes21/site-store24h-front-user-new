# SMSHub - User Frontend

User-facing frontend for the SMSHub platform.

The application provides a React-based web interface integrated with backend services through REST APIs, with authentication, user account management and platform features.

## Features

- User authentication
- User account management
- REST API integration
- Client-side routing
- Application state management
- Forms and validation
- Responsive user interface
- Data visualization
- Internationalization support
- Reusable UI components

## Technologies

- React
- JavaScript
- Vite
- Redux
- Redux Toolkit
- Redux Saga
- Axios
- React Router
- Material UI
- Bootstrap
- Formik
- Firebase
- i18next
- ApexCharts
- Chart.js
- ECharts
- Leaflet

## Architecture

The application follows a component-based React architecture.

The main areas of the project include:

- User-facing pages
- Authentication
- Account management
- API communication
- Application state management
- Routing
- Forms and validation
- Reusable UI components
- Data visualization

The frontend communicates with backend services through HTTP APIs using Axios.
